# ThermalIQ Release Checklist

## Ed25519 Signing Keypair (required before first release)

The Tauri updater uses Ed25519 signatures to verify update packages.
`tauri.conf.json` reads the public key from the `TAURI_SIGNING_PUBLIC_KEY`
environment variable and the private key from `TAURI_SIGNING_PRIVATE_KEY`.

### One-time keypair generation

```bash
# Requires @tauri-apps/cli (npm) or cargo-tauri
npx @tauri-apps/cli signer generate -w /tmp/thermaliq-updater.key
# Output: private key file at /tmp/thermaliq-updater.key
#         public key printed to stdout, e.g.:
#   Public key: dW50cnVzdGVkIGNvbW1lbnQ6IG1pbmlzaWduIHB1YmxpYyBrZXkgRkE...
```

### Adding secrets to GitHub

1. Copy the **public key** (base64 line printed to stdout) into:
   - Repository Settings > Secrets and variables > Actions
   - Name: `TAURI_SIGNING_PUBLIC_KEY`
   - Also set it in `tauri.conf.json` `plugins.updater.pubkey` if not using env var substitution

2. Copy the **private key file contents** into:
   - Repository Settings > Secrets and variables > Actions
   - Name: `TAURI_SIGNING_PRIVATE_KEY`

3. Delete `/tmp/thermaliq-updater.key` after adding it to GitHub Secrets.
   Never commit the private key — it is covered by `*.key` in `.gitignore`.

### CI environment

The release workflow must export both secrets before `cargo tauri build`:

```yaml
env:
  TAURI_SIGNING_PUBLIC_KEY: ${{ secrets.TAURI_SIGNING_PUBLIC_KEY }}
  TAURI_SIGNING_PRIVATE_KEY: ${{ secrets.TAURI_SIGNING_PRIVATE_KEY }}
```

## Update check behaviour

- Automatic background check runs at app launch if `auto_update_check_enabled = true`
  in `~/.config/thermaliq/settings.toml` (default: enabled).
- Checks are throttled to at most once per 24 hours.
- To disable: add `auto_update_check_enabled = false` to the settings file.

## latest.json endpoint

The updater fetches:
```
https://github.com/lulacoding/thermaliq/releases/latest/download/latest.json
```

This file is generated by the release CI script (`scripts/build_latest_json.sh`)
and uploaded as a release asset. Ensure it is present before the release is published.
